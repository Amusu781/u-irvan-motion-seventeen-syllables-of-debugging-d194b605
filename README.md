A haiku about debugging — three lines in the 5-7-5 shape — written by a program to /output/entry.txt. One concrete image at the centre (a log line, a null where a name should be) and a last line that turns the poem.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
